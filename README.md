# E-Commerce Catalog & Stock Automation Engine

A lightweight, powerful Python automation script designed to help e-commerce store owners streamline their daily operations. This tool automates tedious catalog price updates and monitors inventory metrics to instantly flag low-stock items.

## 🚀 Features
* **Automated Catalog Metrics:** View complete store inventory, pricing, and live stock tracking in a clean, organized console layout.
* **Bulk Catalog Update:** Run global percentage-based price adjustments instantly across the entire product database.
* **Smart Low-Stock Tracker:** Automatically scans stock quantities against a set threshold, generates instant alerts, and simulates exporting logs to the store backend server.

## 🛠️ Technology Stack & Compliance
* **Language:** Python 3.x
* **Standards:** 100% clean code conforming to **PEP 8** coding standards for maximum readability and robust logic.
* **Compatibility:** Fully optimized to run seamlessly on both PC environments and mobile-based Python IDEs (like Replit, Pydroid 3, or Pythonista).

## 🖥️ How It Works (Live Preview)
1. **View Catalog:** Displays product IDs, names, prices, and stock counts.
2. **Bulk Pricing:** Enter any positive or negative percentage to update store-wide pricing in one click.
3. **Stock Analysis:** Scans your inventory and immediately triggers a critical `[ALERT]` for items below the safety limit (Threshold = 5).
